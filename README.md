# Data-Analyst-ML-Project
🛍️ Customer Segmentation Using Machine Learning
📌 Project Overview

This project focuses on customer segmentation using unsupervised machine learning techniques to group customers based on demographic, household, and income-related attributes.
The goal is to derive actionable business insights that can help marketing teams design targeted campaigns, improve customer experience, and increase revenue.

🎯 Business Objective

Retail businesses serve diverse customer groups with different needs. Treating all customers the same leads to inefficient marketing spend.

Objective of this project:

Identify distinct customer segments

Understand behavioral and demographic patterns

Recommend data-driven marketing strategies for each segment

🧠 Approach & Methodology
1. Data Preprocessing

Handled missing values and data inconsistencies

Encoded categorical variables using Label Encoding

Scaled numerical features using StandardScaler

2. Dimensionality Reduction

Applied Principal Component Analysis (PCA)

Reduced high-dimensional data while preserving maximum variance

Enabled better visualization and clustering performance

3. Clustering Technique

Used K-Means Clustering

Determined optimal number of clusters using the Elbow Method

Final model identified 4 distinct customer clusters

4. Evaluation & Visualization

Visualized clusters in 2D and 3D space

Interpreted clusters using demographic and income variables

Converted technical clusters into real-world customer personas

🛍️ Customer Cluster Insights & Marketing Strategies
🔹 Cluster 0 – Older Parents with Teenagers

Profile

Parents with 2–4 family members

Teenagers at home

Relatively older demographic

Marketing Strategy

Focus on convenience and family value

Multi-buy discounts on household staples

Ready-made meals and family-sized packs

Traditional marketing channels + digital ads

🔹 Cluster 1 – Young Parents with Small Children

Profile

Mostly parents with one young child

Smaller families (up to 3 members)

Younger age group

Marketing Strategy

Child-centric and premium-quality products

Baby & toddler-focused promotions

Personalized app-based coupons

Social media and digital-first campaigns

🔹 Cluster 2 – High-Income Couples / Singles

Profile

Non-parents

Small households (1–2 members)

High-income group

Mixed age range

Marketing Strategy

Premium and gourmet product focus

Emphasize quality over discounts

Specialty food bundles and exclusive offerings

Elegant email newsletters and curated experiences

🔹 Cluster 3 – Older, Large Families with Budget Constraints

Profile

Parents with 2–5 family members

Teenagers present

Older demographic

Lower-income group

Marketing Strategy

Savings-driven marketing

Store-brand and private-label promotions

Bulk-size discounts

Loyalty programs with high-value rewards

📈 Key Outcomes

Identified 4 actionable customer segments

Enabled personalized marketing strategies

Demonstrated how ML insights translate into business decisions

Showcased end-to-end data analyst + ML workflow
